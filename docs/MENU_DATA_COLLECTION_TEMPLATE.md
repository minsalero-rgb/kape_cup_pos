## Collection notes

- Use one product entry for each actual menu product; copy the entry as needed.
- Record prices exactly as confirmed by the owner. Keep size-specific prices in the size table and modifier additional prices in the modifier table.
- Use `None` for products with no size variations or no modifiers, and `Pending` for details not yet confirmed.
- This template is for collecting menu facts only. It does not define database structure, create menu records, or authorize assumptions about products, prices, sizes, modifier behavior, or availability.
